# Security policy

## Reporting a concern

While the repository is private, contact the repository owner privately. If the project becomes public and GitHub private vulnerability reporting is enabled, use that reporting form.

Do not include tokens, cookies, private server addresses, coordinates, or unredacted personal information.

Relevant concerns include unexpected file or network access, unsafe configuration handling, behavior outside local particle rendering, and release artifacts that do not match tagged source.

Server-rule approval is a policy decision, not a security guarantee. CoreTune remains disabled by default.
