# Privacy

FPS Tune does not collect or transmit user data.

It reads only `config/fpstune.properties` and, during the one-time rename migration, an existing `config/coretune.properties`. It stores only the local configuration files.

The optional Mod Menu screen edits that same local configuration and does not add a network, telemetry, or account path.

There is no telemetry, analytics, advertising, account system, update checker, remote configuration, or custom network connection.
